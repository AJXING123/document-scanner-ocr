# 文档扫描预处理工具（OCR 前置）

一个基于经典计算机视觉算法的文档扫描预处理工具：上传文档照片后自动检测纸张四角，
完成透视矫正与扫描增强（灰度 / 黑白），输出适合 OCR 识别的清晰图片。
自动检测失败时支持鼠标点击四点手动矫正，全程在浏览器中完成。

## 项目功能

- **图片上传**：支持 JPG / JPEG / PNG，校验空文件、损坏文件与超大文件（≤ 20MB），
  中文文件名安全（基于字节流解码），大图自动等比缩放（最长边 2000px）防止内存问题。
- **自动检测**：灰度化 → 高斯降噪 → Canny 边缘 → 形态学闭运算 → 轮廓筛选，
  按面积占比、凸性、四角形条件过滤，自动排除贴满整图的照片边框误检。
- **透视矫正**：基于 `cv2.getPerspectiveTransform()` + `cv2.warpPerspective()`，
  输出尺寸按四条边长估算并限制上限。
- **手动四点兜底**：检测失败或结果不准时，可在图片上直接点击四点
  （依赖 streamlit-image-coordinates），或用坐标输入框精确微调，实时预览四边形。
- **图像增强**：中值滤波去噪、基于大核中值滤波背景估计的除法去阴影、
  自适应高斯二值化（邻域大小与偏移量 C 可调），支持灰度 / 黑白两种输出模式。
- **结果展示与下载**：原图 / 矫正图 / 最终扫描图三栏对比，
  一键下载 PNG，也可保存到本地 `output/` 目录（自动避免覆盖同名文件）。
- **异常处理**：空输入、重复角点、非法四边形、编码失败等均给出明确中文提示，不崩溃。

## 技术栈

Python 3 · OpenCV（opencv-python）· NumPy · Streamlit · Pillow · pytest
纯经典视觉算法，无深度学习模型，无需 GPU。

## 环境要求

- Python 3.10+
- 操作系统：Linux / macOS / Windows 均可
- 无系统级额外依赖（OpenCV 通过 pip  wheel 安装）

## 安装步骤

```bash
git clone <仓库地址>
cd document-scanner
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 启动命令

```bash
streamlit run app.py
```

浏览器访问终端提示的地址（默认 http://localhost:8501）。

## 使用流程

1. 上传文档照片（可先用 `samples/sample_document.png` 演示）。
2. 程序自动检测纸张四角，界面显示检测状态与角点叠加预览；
   也可调整侧边栏 Canny 阈值后点击"重新自动检测"。
3. 检测失败或结果不准时，将"角点来源"切换为 **手动调整**：
   按左上 → 右上 → 右下 → 左下顺序在图片上点击四点，或在输入框中微调坐标。
4. 点击 **执行透视矫正与增强**，查看原图 / 矫正图 / 扫描图对比。
5. 在侧边栏切换灰度 / 黑白模式并调节增强参数，结果实时刷新。
6. 点击下载按钮保存 PNG，或在页面底部保存到本地 `output/` 目录。

## 核心算法原理

**文档四角检测**
1. 灰度化 + 高斯模糊抑制噪声；
2. Canny 边缘检测（多组阈值重试，兼容强弱对比度场景）；
3. 形态学闭运算 + 膨胀连接断裂边缘；
4. 轮廓按面积降序遍历，`approxPolyDP` 多边形逼近后筛选：
   顶点数 = 4、凸四边形、面积占比在合理区间、不贴满整张照片边框；
5. 四个角点按"左上、右上、右下、左下"规则排序（x+y 与 y−x 极值法）。

**透视矫正**
由排序后的四点估算输出宽高（取对边投影长度的较大值，限制在
16 ~ 2500 px 之间），计算透视变换矩阵并 warp 得到正视图。

**图像增强**
- 去阴影：大核中值滤波估计光照背景，`cv2.divide` 除法归一化拉平光照；
- 黑白模式：在归一化灰度图上做自适应高斯阈值二值化，邻域与偏移量可调。

## 当前局限性

- 自动检测依赖文档与背景的对比度，对无边框、与背景同色或严重反光的纸张可能失败
  （此时请使用手动四点调整）。
- 去阴影基于大核背景估计，对极不均匀的强光照（如局部强光斑）效果有限。
- 透视矫正输出尺寸按投影边长估算，无法还原纸张真实物理宽高比。
- 暂不支持批量处理与 OCR 识别。

## 后续扩展方向

- 批量扫描：多图上传、队列处理与打包下载。
- Tesseract OCR 集成：在扫描增强结果上直接输出文本，形成"扫描 → OCR"闭环。
- 更多输出模式（彩色增强、magic color）、自动旋转校正、PDF 导出。
